# Наргиза — Кыз узатуу

Приглашение на React и Vite по визуальному образцу https://priglasi-diamond.com/tancholpon.

## Запуск

```sh
npm install
npm run dev
```

`npm run build` создаёт статическую сборку в `dist`. Её можно разместить на любом статическом хостинге. `npm run preview` запускает проверку сборки.

## Данные

17 октября 2026 года, 11:00, часовой пояс Кыргызстана UTC+06:00.

Нарын облусу, Ат-Башы району, Калинин айылы.

Текст и дата находятся в `src/main.jsx`, стили в `src/styles.css`. `src/layers.json` содержит измеренные координаты, размеры и анимации оригинальных декоративных слоёв.

## Особенности

- React-компоненты, обычный CSS, IntersectionObserver. Скриптов, API и зависимости от Tilda в работающем сайте нет.
- Изображения, шрифты и музыка загружаются из локального `public/assets`. Пользователь подтвердил разрешение на фотографии и аудио. Происхождение ресурсов сохранено в `reference/assets.json`.
- Музыка автоматически запускается при открытии, если браузер разрешает звук. Если автозапуск заблокирован, воспроизведение начинается при первом касании, клике или нажатии клавиши. Прокрутка и возврат наверх не останавливают трек. Кнопка позволяет поставить музыку на паузу; после ручной паузы взаимодействия со страницей не запускают её снова.
- Таймер считает до `2026-10-17T11:00:00+06:00` и останавливается на нуле. Календарь построен для октября 2026; сердцем отмечена суббота, 17 число.
- Анкета и просьба подтвердить присутствие удалены. После программы следует блок родителей.
- Карта открывает поиск нового адреса. Координаты дома не выдумываются.
- Исходные надписи были частью PNG. Изменяемые надписи воссозданы HTML-текстом со шрифтами Great Vibes и Cormorant; неизменяемые декоративные надписи сохранены как изображения.
- У оригинала полноценная композиция существует только до 480 px; на большом экране оригинал обрезает содержимое. Здесь та же мобильная композиция шириной 390 px показывается по центру.
- В программе указан только предоставленный пользователем час 11:00. Старые 15:00, 16:00 и 22:00 удалены; второй и третий пункты не содержат неподтверждённых часов.
- Рекламные контакты оригинала заменены данными приглашения.
- Учитывается `prefers-reduced-motion`, есть подписи полей, управление с клавиатуры и подпись музыкальной кнопки.

## Проверка

Скриншоты находятся в `screenshots`, результаты браузерной проверки — `reference/verification.json`. Проверены мобильные ширины 320, 375, 390 и 430 px, планшет 768 px и компьютер 1440 px. Проверены загрузка изображений, отсутствие горизонтальной прокрутки, размещение текста, воспроизведение аудио, отсутствие анкеты и отсутствие внешних запросов.

Исходные HTML-вложения в рабочей папке отсутствовали; для анализа скачан HTML указанного пользователем оригинального сайта. Снимки оригинала сделаны непосредственно с опубликованного сайта.
